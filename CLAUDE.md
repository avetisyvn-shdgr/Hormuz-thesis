# CLAUDE.md — Compatibility entry point

Read and follow `AGENTS.md` in this repository root. It is the single canonical
instruction file for the technical thesis project.

This file deliberately contains no independent research design or operating
rules. Keeping a second copy caused the previous causal/ton-mile design to remain
active after the thesis had moved to an explicitly non-causal public-data
throughput-shortfall design.

Existing source code, tests, and historical documentation sometimes cite
`CLAUDE.md rule 1` through `CLAUDE.md rule 8`. Those references map to the
same-numbered rules in `AGENTS.md`.

If any historical document conflicts with `AGENTS.md`, apply the source-of-truth
order defined in `AGENTS.md` and report the conflict. Do not revive causal ATT,
freight-rate, dose-response, mediation, g-formula, PCMCI, or aggregate ton-mile
multiplier claims without an explicit new decision from the researcher.
